# AlgoStep 后端使用指南

> 启动后端 → 注册登录 → 测试全部 22 个接口的完整流程

---

## 一、启动后端

### 1.1 启动命令

在 PowerShell 中执行：

```powershell
# 1. 设置环境变量（每次新开终端都需要，或者配置到系统环境变量）
$env:JAVA_HOME = "D:\啵啵\Trae\Project\Java\jdk-17.0.2"
$env:PATH = "$env:JAVA_HOME\bin;D:\啵啵\Trae\Project\Java\apache-maven-3.9.9\bin;" + $env:PATH

# 2. 进入后端目录
cd "D:\啵啵\Trae\Project\Java\AlgoStep\algostep-backend"

# 3. 启动（首次会下载依赖，约 1-2 分钟）
mvn spring-boot:run
```

### 1.2 启动成功标志

看到以下日志表示启动成功：

```
Tomcat started on port 8080 (http) with context path ''
Started AlgoStepApplication in X.XXX seconds
```

### 1.3 访问地址

| 地址 | 说明 | 是否需要登录 |
|---|---|---|
| http://localhost:8080/ | 首页（系统状态） | 否 |
| http://localhost:8080/health | 健康检查 | 否 |
| http://localhost:8080/doc.html | Knife4j API 文档（在线调试） | 否 |
| http://localhost:8080/h2-console | H2 数据库控制台 | 否 |
| http://localhost:8080/api/auth/register | 注册 | 否 |
| http://localhost:8080/api/auth/login | 登录 | 否 |
| http://localhost:8080/api/algorithms | 算法列表 | 否 |

> 根路径现在返回系统状态 JSON，不再是 401 了。

### 1.4 H2 控制台使用

访问 http://localhost:8080/h2-console

- **JDBC URL**: `jdbc:h2:mem:algostep`
- **User Name**: `sa`
- **Password**: （空）

连接后可以查看所有表和数据。常用查询：
```sql
SELECT * FROM SYS_USER;
SELECT * FROM ALGORITHM;
SELECT * FROM LEARNING_PROGRESS;
SELECT * FROM FAVORITE;
SELECT * FROM NOTIFICATION;
```

> 注意：H2 是内存数据库，**重启后端后所有数据会清空**（算法初始数据会重新加载）。

## 二、Knife4j 在线调试使用方法

### 2.1 打开文档

启动后端后，浏览器访问 **http://localhost:8080/doc.html**

左侧可以看到所有接口分组：
- 公共接口（首页/健康检查）
- 认证管理（注册/登录/登出/刷新/当前用户）
- 用户管理（个人信息/修改信息/修改密码）
- 算法管理（算法列表/算法详情）
- 学习进度（进度列表/单个进度/保存进度/学习统计）
- 收藏管理（收藏列表/添加收藏/取消收藏）
- 通知管理（通知列表/标记已读/全部已读/未读数量）

### 2.2 发送请求的步骤

1. 点击左侧某个接口（如「认证管理 → 注册」）
2. 点击右侧「调试」tab
3. 填写请求参数（body 参数填在下方 JSON 编辑框）
4. 点击「发送」按钮
5. 右侧下方查看响应结果

### 2.3 设置 Token 认证（重要！）

需要认证的接口必须先设置 Token，否则返回 401：

1. 先调用「登录」接口，拿到 `data.token` 的值
2. 点击页面右上角的 **Authorize** 🔒 按钮
3. 在输入框中填入：`Bearer {你的token}`（注意 Bearer 后面有空格）
4. 点击「Authorize」→ 点击「Close」
5. 之后所有请求都会自动带上 Token

## 三、完整测试流程（推荐顺序）

### 第 1 步：注册用户

接口：`POST /api/auth/register`

```json
{
  "username": "testuser",
  "password": "123456",
  "email": "test@example.com"
}
```

预期返回：
```json
{ "code": 200, "msg": "操作成功", "data": null }
```

### 第 2 步：登录

接口：`POST /api/auth/login`

```json
{
  "username": "testuser",
  "password": "123456"
}
```

预期返回（data 里有 token）：
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "refreshToken": "eyJhbGciOiJIUzI1NiJ9...",
    "userId": 1,
    "username": "testuser",
    "nickname": "testuser",
    "role": "USER"
  }
}
```

**把 token 复制下来，设置到 Knife4j 的 Authorize 里**（格式：`Bearer {token}`）。

### 第 3 步：获取当前用户信息

接口：`GET /api/auth/me` （需要认证）

预期返回当前登录用户的信息。

### 第 4 步：修改个人信息

接口：`PUT /api/user/profile` （需要认证）

```json
{
  "nickname": "算法小达人",
  "avatar": "https://example.com/avatar.jpg"
}
```

### 第 5 步：修改密码

接口：`PUT /api/user/password` （需要认证）

```json
{
  "oldPassword": "123456",
  "newPassword": "654321"
}
```

> 测试完可以改回 `123456`，方便后续测试。

### 第 6 步：查看算法列表

接口：`GET /api/algorithms` （无需认证）

返回 12 个算法，按分类排序。

**按分类筛选：**
- `GET /api/algorithms?category=sort` → 排序算法
- `GET /api/algorithms?category=dp` → 动态规划
- `GET /api/algorithms?category=search` → 搜索算法

### 第 7 步：查看算法详情

接口：`GET /api/algorithms/1` （无需认证）

返回 id=1 的算法详情（冒泡排序）。

### 第 8 步：保存学习进度

接口：`PUT /api/progress` （需要认证）

```json
{
  "algorithmId": 1,
  "stepIndex": 5,
  "totalSteps": 12,
  "studyTime": 180
}
```

预期返回：
```json
{
  "code": 200,
  "data": {
    "algorithmId": 1,
    "algorithmName": "bubble-sort",
    "algorithmNameZh": "冒泡排序",
    "category": "sort",
    "difficulty": "beginner",
    "status": "LEARNING",
    "stepIndex": 5,
    "totalSteps": 12,
    "studyTime": 180
  }
}
```

> **自动状态流转规则：**
> - stepIndex = 0 → UNSTARTED（未开始）
> - 0 < stepIndex < totalSteps → LEARNING（学习中）
> - stepIndex >= totalSteps → MASTERED（已掌握）

### 第 9 步：获取全部学习进度

接口：`GET /api/progress` （需要认证）

返回所有有学习记录的算法进度，按最近更新倒序。

### 第 10 步：获取单个算法进度

接口：`GET /api/progress/1` （需要认证）

获取 id=1 算法的学习进度。如果从未学习过，返回默认进度（status=UNSTARTED）。

### 第 11 步：学习统计

接口：`GET /api/progress/stats` （需要认证）

返回：
```json
{
  "total": 1,
  "unstarted": 0,
  "learning": 1,
  "mastered": 0,
  "totalStudyTime": 180
}
```

### 第 12 步：添加收藏

接口：`POST /api/favorites/1` （需要认证）

收藏 id=1 的算法（冒泡排序）。

再收藏 id=2 的试试：
- `POST /api/favorites/2`

### 第 13 步：收藏列表

接口：`GET /api/favorites` （需要认证）

返回所有收藏的算法，含算法名称、分类、难度、URL。

### 第 14 步：取消收藏

接口：`DELETE /api/favorites/1` （需要认证）

取消收藏 id=1 的算法。

### 第 15 步：通知列表

接口：`GET /api/notifications` （需要认证）

默认第一页，每页 10 条。因为目前没有通知数据，返回空列表。

**参数：**
- `pageNum`: 页码，默认 1
- `pageSize`: 每页数量，默认 10
- `unreadOnly`: true 只看未读，默认全部

返回中附带 `unreadCount`（未读数量）。

### 第 16 步：未读数量

接口：`GET /api/notifications/unread-count` （需要认证）

返回未读通知总数，用于前端红点提示。

### 第 17 步：登出

接口：`POST /api/auth/logout` （需要认证）

当前是无状态 JWT，登出仅记录日志（客户端丢弃 Token 即可）。后续接入 Redis 后会真正失效 Token。

### 第 18 步：刷新 Token

接口：`POST /api/auth/refresh` （无需认证，但需要 refreshToken）

```json
{
  "refreshToken": "登录时返回的 refreshToken"
}
```

返回新的 token 和 refreshToken。

## 四、常见问题

### 4.1 访问 localhost:8080 还是 401？

**已修复**：现在根路径 `/` 和 `/health` 是公开的。如果还看到 401，请重新启动后端（代码修改后需要重启）。

### 4.2 H2 控制台登录不上？

检查 JDBC URL 是否正确：`jdbc:h2:mem:algostep`

注意：后端重启后 H2 数据会清空，算法初始数据会重新加载，用户数据需要重新注册。

### 4.3 Knife4j 页面空白？

确保后端正常启动。访问 http://localhost:8080/v3/api-docs 看是否有 JSON 返回（API 元数据）。

### 4.4 接口返回 401？

- 检查 Token 是否在 Authorize 中正确设置
- 格式必须是 `Bearer {token}`（Bearer 后有空格）
- Token 是否过期（默认 2 小时有效期）

### 4.5 接口返回 403？

权限不足。普通用户（ROLE_USER）可以访问所有业务接口，目前没有 ADMIN 专属接口。

### 4.6 想切换到 MySQL？

1. 安装 MySQL 8 并启动
2. 执行 `src/main/resources/sql/init.sql` 建库建表
3. 修改 `application.yml` 中的 `spring.profiles.active` 为 `dev`
4. 修改 `application-dev.yml` 中的数据库连接信息（用户名/密码）
5. 重启后端

## 七、下一步学习建议

现在基础 CRUD 全部完成，可以继续进阶：

1. **Redis 缓存接入** — 让项目有缓存能力，性能提升 + Token 服务端失效
2. **Kafka 异步化** — 进度写入用消息队列削峰，面试亮点
3. **限流 + AOP** — 登录限流、操作日志
4. **Docker 部署** — 容器化，一键部署

每完成一个阶段，记得更新简历中的项目描述，面试时可以讲对应的技术点。
