DP

动态规划 Dynamic Programming

5 个算法
爬楼梯 Climb Stairs
每次可上 1 或 2 级台阶，到达第 n 级有多少种走法。
入门 · Beginner O(n)
0-1背包 0-1 Knapsack
每个物品最多选一次，在背包容量限制下最大化价值。
基础 · Basic O(nW)
最长递增子序列 LIS
求数组中最长递增子序列的长度，O(n log n) 优化。
基础 · Basic O(nlog n)
完全背包 Complete Knapsack
每个物品可重复选取，比较与 0-1 背包的递推差异。
进阶 · Advanced O(nW)
最长公共子序列 LCS
求两个字符串的最长公共子序列长度，经典二维 DP 问题。
进阶 · Advanced O(mn)
S

排序 Sorting

4 个算法
冒泡排序 Bubble Sort
相邻元素两两比较交换，最大值逐步浮到末尾，排序经典。
入门 · Beginner O(n²)
选择排序 Selection Sort
每轮从未排序部分选出最小值，放到已排序部分末尾。
入门 · Beginner O(n²)
插入排序 Insertion Sort
将元素依次插入已排序部分的正确位置，稳定且简单。
入门 · Beginner O(n²)
快速排序 Quick Sort
选取基准值分区，递归排序左右两部分，分治经典。
基础 · Basic O(nlog n)
Q

搜索 Search

3 个算法
二分查找 Binary Search
在有序数组中折半查找目标值，每次排除一半搜索空间。
入门 · Beginner O(log n)
深度优先搜索 DFS
图与树遍历的核心算法，沿一条路径尽可能深地搜索，回溯后继续其他分支。
基础 · Basic O(V+E)
广度优先搜索 BFS
按层遍历图的节点，适用于最短路径问题，通常使用队列实现。
基础 · Basic O(V+E)
